# Flight Canvas

一个基于 HTML 的本地飞行记录可视化编辑器。导入自己的航班数据，在自由画布上组合航线地图、统计卡片与旅行故事，并导出可分享的图片或视频。
源码全部由 GPT-5.6 撰写，灵感来源于 ios 系统的桌面小组件。

## 它能做什么

- 导入 CSV、XLS、XLSX、JSON 和 Flight Canvas 项目文件。
- 按日期、航司、机型和标签筛选飞行记录。
- 生成航线地图、飞行统计、航司/机型排行、特色航班等可视化卡片。
- 在网格画布上拖动、缩放、排列和叠放卡片。
- 自动将项目保存在浏览器本地；你的航班数据不会上传到服务器。
- 导出 PNG 图片或带转场效果的 MOV 视频。

## 开始使用

本项目部署后可直接在浏览器中使用，无需注册、安装或上传个人飞行数据。
学习成本较低

### 数据格式

导入表格至少应包含以下信息：

| 字段 | 示例格式 |
|---|---|
| 日期 | 2026/08/01 |
| 航班号 | HU1234 |
| 起飞时间 / 到达时间 | 12:34 |
| IATA 出发 / 到达机场 | PEK |
| 里程 | 1234 |
| ICAO 机型 | A339 |
| 备注(可选) | 彩绘 |
| 标签(可选) | HNA666 |

列的顺序不影响导入。应用会识别常见的中英文列名，例如 `Date`、`No.`、`dept.time`、`dept`、`dst.time`、`dst`、`mileage`、`aircraftType` 和  `note`、`tag`。

### 导出

在导出面板选择分辨率和导出格式：

- `PNG`：适合分享统计海报、行程总结和静态航线图。
- `MOV`：适合分享动态飞行回顾；完整叠放会按设定的方向和周期生成转场动画（可二次加工 live）。

分辨率倍率越高，导出的画面越清晰，但生成时间和浏览器内存占用也会相应增加。MOV 导出受限于作者技术，进度极慢，请耐心等待，但二次加工为 Live 效果很流畅。

## 数据与隐私

日常编辑、筛选和导出均在你的浏览器中完成。项目会通过 IndexedDB 自动保存到当前浏览器；清除浏览器站点数据可能会删除本地项目，重要作品请导出项目文件留存。
